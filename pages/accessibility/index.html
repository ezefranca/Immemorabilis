Accessibility

Built to be usable.

Immemorabilis uses native Apple controls and accessibility information so tasks and actions can be understood without relying on appearance alone.

Last reviewed August 26, 2026

VoiceOver and named controls

Icon-only controls have spoken names, including Settings, New Task, Dictate a Task, Save, Close, Complete, and Re-remind. Accent choices report both their color and whether they are selected.

Text and layout

The app uses Apple’s system type styles throughout most of the interface. These styles respond to Dynamic Type and Bold Text. We continue to test long labels and the largest accessibility text sizes as the interface develops.

Color and appearance

Light and dark appearances use separate palettes. Actions also use symbols, labels, shape, and position, so color is not the only indication of meaning. Red and blue accent choices are available in Settings.

System assistive technologies

Named native controls make the main flows available to Voice Control and Switch Control. Notification behavior still depends on the accessibility, notification, Focus, and sound settings configured on the device.

Known work

Accessibility is tested alongside navigation and core task flows, but it is not finished once. Extreme text sizes, localization, reading order, contrast, and reduced-motion behavior remain part of release testing.

Report a problem

Open an issue on GitHub and describe the screen, assistive technology, device, and iOS version. Do not include private reminder content or other sensitive information.
